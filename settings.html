Settings

Open Espresso › Settings… (⌘,).

General

Setting What it does
Global shortcut The keys that open The Shot from any app. Default ⌥Space. Click the box and press new keys; click ✕ to remove the shortcut.
Shortcut opens The Shot (quick search) or The main window.
Open at login Start Espresso when you log in (off by default).
Show icon in menu bar A cup icon in the menu bar with Pull a Shot, New Window, Settings and Quit (off by default).
When the last window closes Keep Espresso open (the shortcut keeps working and indexes stay fresh) or Quit Espresso.
Check for updates automatically Check once a day for a new version (on by default).
Download and install updates automatically Install new versions when you quit Espresso, without asking (off by default).
Get beta versions Also receive preview versions before they're final.
Check Now Check for an update right away (also Espresso › Check for Updates…).

Disks

Setting What it does
Indexed disks Every disk Espresso knows, with its status and number of items. The … menu offers Update Index, Fresh Grind and Remove Index…. Connected disks that aren't indexed yet have an Index button.
Decaf · Excluded folders Folders whose contents are not indexed: add with +, remove with −.
Also skip folders named Skip common folders by name wherever they are: node_modules, .git, DerivedData, .build, Pods, __pycache__, .venv, target.
Show hidden files Show hidden files in results by default.
Show contents of apps and packages Show files inside apps and packages (on by default).
Index network volumes Offer shared network folders for indexing (off by default).
Full Disk Access Whether Espresso can see protected folders, with a button to open System Settings.

Search

Setting What it does
Defaults for new windows Match case · Match whole words · Match the full path · Ignore diacritics · Regular expressions. Each window can still change them from the Options button.
Macros Name and expansion of your macros. Add with +, remove with −, edit in place.
Your usual · Saved searches Rename, change or delete your saved searches.

Metadata

Choose which extended details Espresso reads in the background:

  • Images: dimensions and date taken
  • Audio: duration
  • Video: duration
  • Documents: author and pages
  • Finder tags

Turning a kind off stops reading it for new files; details already read are kept.

Support Espresso

Espresso is free and has no ads. If it saves you time, Buy us a coffee opens our donation page in your browser, where you pay what you want. Nothing in Espresso is locked, and it will never nag you.
