# Espresso

Instant file search for every disk on your Mac, including the ones that aren't connected.
Results update on every keystroke; names, sizes and dates of every file, hidden and system files
too, in a native Finder-style window. Nothing leaves your Mac.

- **Documentation:** https://docs.espressoformac.com
- **Download:** https://espressoformac.com/download/ (macOS 14 Sonoma or later, Apple silicon and Intel), or with Homebrew: `brew install mokasolutions/tap/espresso-search`. Espresso updates itself afterwards.
- **Problems and ideas:** [Issues](https://github.com/mokasolutions/espresso-releases/issues)
- **Support:** support@mokasolutions.dev

## Free and Pro

**Espresso Free** is free forever for personal, non-commercial use: every disk, live updates, the
full search syntax, Blends, saved searches, macros, The Shot and two offline disks.

**Espresso Pro** adds unlimited offline disks, Disk Info, camera, codec, music and document
details, bulk rename, CSV export, the command line, Shortcuts, Raycast, Alfred and AI assistants
(MCP), Ask the Barista (search in your own words, on your Mac), search inside documents and
photos, and the Timeline. One payment, every update, up to three Macs; try it free for 14 days.
Using Espresso at work needs Pro. Details: [Espresso Pro](https://docs.espressoformac.com/pro).

## About this repository

Espresso is closed source. This repository holds only this README and the public issue tracker;
the application source code is not published here. Downloads come from
[espressoformac.com](https://espressoformac.com/download/) and the user guide lives at
https://docs.espressoformac.com.
