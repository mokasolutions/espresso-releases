# Espresso

Instant file search for every disk on your Mac — including the ones that aren't connected.

- **Documentation:** https://mokasolutions.github.io/espresso-releases/
- **Downloads:** [Releases](https://github.com/mokasolutions/espresso-releases/releases) (macOS 14 Sonoma or later)
- **Problems and ideas:** [Issues](https://github.com/mokasolutions/espresso-releases/issues)

Espresso is free and closed source. This repository holds the public documentation and the
release downloads; the application source code is not published here.
